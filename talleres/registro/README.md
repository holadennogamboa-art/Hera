# Registro

- `BITACORA.csv` — una línea por bloque. Estados: `hecho`, `parcial`, `perdido`.
- `YYYY-Www.md` — las revisiones semanales archivadas, una por viernes.

La bitácora no es burocracia: es la única prueba objetiva de si el sistema funciona.
Sin ella, la revisión semanal se convierte en una conversación sobre sensaciones.
