# PASO 1: CREAR GOOGLE SHEET (15 minutos)

## 1.1 - Abre Google Sheets

### Si tienes Gmail:
1. Abre tu navegador (Chrome, Safari, Firefox)
2. Ve a: https://sheets.google.com/
3. Clickea el botón azul **"+ Crear"** (esquina izquierda)
4. Clickea **"Hoja de cálculo en blanco"**

### Si no tienes Gmail:
1. Ve a: https://docs.google.com
2. Clickea **"Crear"** → **"Hoja de cálculo"**

**Resultado:** Ves una hoja vacía con cuadrículas. ✅

---

## 1.2 - Configura los encabezados

Vas a escribir los títulos. Muy fácil.

**Clickea en la celda A1** (esquina arriba a la izquierda)

Escribe:
```
DATE
```

Presiona **TAB** (no ENTER)

Escribe:
```
FOLLOWERS
```

Presiona **TAB**

Escribe:
```
ENGAGEMENT_%
```

Presiona **TAB**

Escribe:
```
COMMENTS
```

Presiona **TAB**

Escribe:
```
SAVES
```

Presiona **TAB**

Escribe:
```
NOTES
```

Presiona **ENTER**

**Deberías ver esto:**

| DATE | FOLLOWERS | ENGAGEMENT_% | COMMENTS | SAVES | NOTES |
|------|-----------|---|---|---|---|
|      |           |   |   |   |   |

---

## 1.3 - Añade datos de HOY

**Clickea en A2** (celda debajo de "DATE")

Escribe la fecha de hoy:
```
2026-05-21
```

Presiona **TAB**

En FOLLOWERS, escribe tu número actual:
```
0
```

(O el número que tengas ahora en Instagram)

Presiona **TAB**

En ENGAGEMENT_%, déjalo vacío por ahora

Presiona **TAB**

En COMMENTS, escribe:
```
0
```

Presiona **TAB**

En SAVES, escribe:
```
0
```

Presiona **TAB**

En NOTES, escribe:
```
Baseline - Starting today
```

Presiona **ENTER**

**Deberías ver esto:**

| DATE | FOLLOWERS | ENGAGEMENT_% | COMMENTS | SAVES | NOTES |
|------|-----------|---|---|---|---|
| 2026-05-21 | 0 | | 0 | 0 | Baseline - Starting today |

---

## 1.4 - Guarda y nombra el documento

**Arriba a la izquierda** ves "Hoja de cálculo sin título"

Clickea ahí y escribe:
```
EYEHERA - Tracking
```

Presiona **ENTER**

Google lo guarda automáticamente. ✅

---

## 1.5 - Copia el link

En la esquina arriba a la derecha, clickea el botón azul **"Compartir"**

Clickea **"Copiar enlace"**

Pégalo en un lugar seguro:
- Marcadores del navegador
- Un documento de notas
- Slack/email a ti mismo

**✅ PASO 1 COMPLETADO**
