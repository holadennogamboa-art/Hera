# ⚡ Quick Start: Publica en 5 Minutos

## Paso 1: Ver el Carrusel (1 min)

Abre `carousel.html` en tu navegador:
```bash
open carousel.html
# O haz click derecho en el archivo → Abrir con navegador
```

Navega con las flechas o los puntitos. Así se ve en Instagram.

---

## Paso 2: Obtén las Imágenes (2 opciones)

### Opción A: Script Automático (1 min)
```bash
cd /home/user/Hera/assets/pride-carousel-2026/
npm install puppeteer
node generate-images.js
```

Genera 6 imágenes PNG automáticamente.

### Opción B: Manual en Canva (5 min)
1. Ve a canva.com
2. Copia cada slide de `carousel.html`
3. Crea en Canva (1080x1920)
4. Descarga cada uno como PNG

**Colores:** Ver sección "Colores exactos" en README.md

---

## Paso 3: Sube a Instagram (2 min)

### Desktop:
1. instagram.com → Nueva publicación
2. Selecciona "Múltiples fotos o videos"
3. Sube en este orden:
   - slide-1-hero.jpg
   - Flow_202606221356.mp4 (tu video)
   - slide-3-data.png
   - slide-4-cta.png
   - slide-5-manifesto.png
   - slide-6-closing.png
4. Copia el caption de INSTAGRAM-GUIDE.md
5. Publica

### Mobile:
1. Instagram app → + (crear)
2. Toca "Múltiples"
3. Selecciona todas en orden
4. Agrega caption
5. Publica
